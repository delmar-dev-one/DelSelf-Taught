## ⌨️ Controles de Movimento — já existiam, mantidos

| Tecla | Ação |
|---|---|
| `↑` Seta para cima | Astronauta sobe em direção à base |
| `↓` Seta para baixo | Astronauta desce em direção à calçada |
| `←` Seta para esquerda | Astronauta vai para a esquerda |
| `→` Seta para direita | Astronauta vai para a direita |

Cada tecla move **20 pixels** por pressionamento. O jogador não atravessa as bordas da tela — os limites são calculados automaticamente.

## 🔁 Controles de Menu — R existia, M e C são novos

| Tecla | Quando funciona | Ação |
|---|---|---|
| `R` | Tela de Game Over ou Vitória | Reinicia o jogo do zero no modo normal |
| `M` | Tela de Game Over ou Vitória | **NOVO** — inicia o Modo Infinito |

O `R` existia no original mas estava com a condição errada — verificava `faseCompleta` junto com `gameOver`, o que travava o reinício. Agora funciona corretamente.

## 🖱️ Interações automáticas — sem tecla, só colisão

Esses "comandos" acontecem ao tocar objetos na pista:

| Objeto | Cor | Efeito ao tocar |
|---|---|---|
| Power-up `S` | Azul | Ativa escudo por **5 segundos** — imunidade total a colisões |
| Power-up `T` | Roxo | Ativa slow por **4 segundos** — carros na metade da velocidade |
| Power-up `$` | Dourado | **+200 pontos** instantâneos |
| Carro | Vermelho/Laranja/Amarelo/Magenta | Perde 1 vida + explosão + volta à posição inicial |
| Buraco | Oval preta | Perde 1 vida + explosão + volta à posição inicial |
| Zona segura intermediária | Faixa verde | Nenhum dano enquanto estiver nela |
| Base segura (topo) | Verde escuro | Completa a fase + bônus de pontuação |

## 🔢 O que os comandos disparam internamente

```
↑ ↓ ← →
  └→ keyPressed()
       └→ move playerX / playerY
       └→ adicionarParticula()   ← poeira nos pés (NOVO)
       └→ Math.max/min           ← impede sair da tela

Tocar carro ou buraco
  └→ actionPerformed() detecta colisão
       └→ sofrerDano()           ← NOVO método centralizado
            └→ ativarExplosao()
            └→ vidas--
            └→ se vidas == 0: gameOver + salvarRecorde()
            └→ se vidas > 0:  volta à posição inicial

Tocar power-up
  └→ actionPerformed() detecta colisão
       └→ p.coletado = true      ← some da tela
       └→ ativa escudo / slow / pontos

Chegar ao topo
  └→ actionPerformed() detecta playerY < 100
       └→ faseCompleta = true
       └→ Timer de 2.2s → criarCarros() próxima fase

R pressionado no Game Over
  └→ keyPressed()
       └→ reiniciarJogo(false)   ← modo normal

M pressionado no Game Over
  └→ keyPressed()
       └→ reiniciarJogo(true)    ← modo infinito (NOVO)
```

---

## 🚫 O que o original tinha de errado nos comandos

O original tinha um **switch duplicado** dentro de `keyPressed` que nunca era executado porque o `if/else` acima já capturava todas as teclas. Além disso,
 havia código de movimento solto **fora de qualquer método**, o que causava erro de compilação. Tudo foi consolidado em um único bloco dentro de `keyPressed`.
